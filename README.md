# linux-command-cheatsheet
 A collection of essential Linux commands, practical examples, and notes documenting my Linux learning journey.

## 1. Navigation

| Command | Function |
|---|---|
| `pwd` | Displays the current working directory |
| `ls` | Lists files and directories |
| `ls -la` | Lists all files, including hidden files |
| `cd` | Changes directory |
| `cd ..` | Moves one directory backwards |

## 2. File Management

| Command | Function |
|---|---|
| `mkdir` | Creates a directory |
| `touch` | Creates an empty file |
| `cp` | Copies files |
| `mv` | Moves or renames files |
| `rm` | Removes files |
| `cat` | Displays file contents |

## 3. Permissions

| Command | Function |
|---|---|
| `chmod` | Changes file permissions |
| `chown` | Changes file ownership |
| `whoami` | Displays the current username |
| `id` | Displays user and group information |

## 4. System Information

| Command | Function |
|---|---|
| `uname -a` | Displays system information |
| `df -h` | Displays disk space usage |
| `free -h` | Displays memory usage |
| `uptime` | Displays system uptime |
| `top` | Displays running processes |

## 5. Networking

| Command | Function |
|---|---|
| `ip addr` | Displays network interfaces and IP addresses |
| `ping` | Tests network connectivity |
| `ip route` | Displays routing information |
| `ss -tuln` | Displays listening network sockets |
| `traceroute` | Traces the route to a destination |

## Learning Notes

This cheat sheet documents Linux commands I have learned and practised during my cybersecurity journey.
